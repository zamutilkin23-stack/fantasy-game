# как запустить (2 минуты)

## 1. Скачать PHP
Открой в браузере: https://windows.php.net/downloads/releases/php-8.3.13-nts-Win32-vs16-x64.zip
Скачай ZIP. Распакуй в `C:\php`.

## 2. Запустить
Дважды кликни `start_server.bat`.

## 3. Открыть в браузере
Установка: http://localhost:8000/install.php
Сайт: http://localhost:8000/
Админка: http://localhost:8000/admin/
Игра: http://localhost:8000/start
